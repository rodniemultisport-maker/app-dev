# American Sniper

## About the Movie
**American Sniper** is a *biographical war drama* film released in 2014. It was directed by **Clint Eastwood** and is based on the autobiography of Navy SEAL sniper **Chris Kyle**.

---

## Main Cast

- **Sienna Miller** as Taya Kyle
